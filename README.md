 Savoria Premium 🍽️

Savoria Premium adalah platform etalase digital yang dirancang untuk mempromosikan produk kuliner dari UMKM lokal, khususnya di daerah Cikarang dan sekitarnya. Website ini memudahkan masyarakat menemukan jajanan unik dan mendukung pertumbuhan ekonomi kreatif lokal melalui kampanye #BanggaBuatanIndonesia.

 Fitur Utama
Katalog Produk Terkurasi: Menampilkan berbagai produk makanan dan minuman dari mitra UMKM pilihan.
Filter Kategori: Memudahkan pencarian berdasarkan kategori (Makanan Berat, Minuman, Dessert, Makanan Ringan, dan Makanan Pedas).
Informasi Lokasi & Harga: Detail transparan mengenai harga produk dan lokasi fisik UMKM (seperti Cifest, BCM, Jatireja, dll).
Halaman Tentang Kami: Informasi mengenai visi misi platform dalam mendukung produk lokal.
Antarmuka Responsif: Desain modern yang nyaman diakses melalui perangkat desktop maupun mobile.

 🛠️ Teknologi yang Digunakan
Frontend: HTML5, CSS3 (Custom Styling), JavaScript.
Database/Backend: PHP & MySQL (Berdasarkan tab `db_savoria` pada screenshot).
Tools: Visual Studio Code, XAMPP (Localhost).

## 📸 Tampilan Website
### Hero Section
Platform ini menyapa pengguna dengan visual produk yang menggugah selera dan pesan utama "Semua Rasa Favoritmu Ada Di Savoria Premium".

### Menu & Kategori
Pengguna dapat menjelajahi berbagai pilihan kuliner dengan sistem kartu (card) yang informatif, lengkap dengan rating dan jumlah terjual.

🚀 Cara Menjalankan Proyek di Lokal
1.  Clone repositori ini:
    bash
    git clone https://github.com/username/savoria-premium.git
2.  Persiapkan Database:
    Buka XAMPP dan aktifkan Apache serta MySQL.
    Masuk ke `phpMyAdmin` dan buat database baru bernama `db_savoria`.
    Impor file `.sql` (jika tersedia) ke dalam database tersebut.
3.  Pindahkan File:
    Salin folder proyek ke direktori `C:/xampp/htdocs/`.
4.  Akses Website:
    Buka browser dan ketik `localhost/savoriaaa/index.html` (atau `.php`).
